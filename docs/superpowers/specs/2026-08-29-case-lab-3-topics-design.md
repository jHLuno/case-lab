# Case Lab 3 Topics Design

## Goal

Обновить утвержденные темы двух кейсов на странице `/case-lab-3` и показывать одинаковые полные формулировки в Hero и блоке спикеров.

## Scope

- Для `Qara Studios` использовать: `Как коллаборации и маркетинг масштабировали OYU Fest?`
- Для `Invictus GO` использовать: `Как построить маркетинг, который масштабируется вместе с бизнесом?`
- Обновить Hero-подписи и `title` кейсов спикеров.
- Оставить тему `Forte Bank × GForce Grey`, описания кейсов, порядок, стили и metadata без изменений.

## Implementation

Изменить только `app/sections/CaseLab3Hero.tsx` и `app/sections/CaseLab3Speakers.tsx`. Вынесение данных в общий модуль не требуется: для этой точечной замены достаточно синхронно обновить четыре текстовых значения.

## Verification

Проверить совпадение новых формулировок в обоих компонентах, отсутствие старых тем, затем запустить релевантные тесты, TypeScript, lint и `git diff --check`.
