# Case Lab 3 Topics Design

## Goal

Обновить утвержденные темы трех кейсов на странице `/case-lab-3` и показывать одинаковые формулировки в Hero и блоке спикеров.

## Scope

- Для `Qara Studios` использовать: `Как коллаборации и маркетинг масштабировали OYU Fest?`
- Для `Invictus GO` использовать: `Как построить маркетинг, который масштабируется вместе с бизнесом?`
- Для `Forte Bank × GForce Grey` использовать: `Как арт-инсталляция ForteBank разошлась по всему миру?`
- Обновить Hero-подписи и `title` кейсов спикеров.
- Описания кейсов, порядок, стили и metadata оставить без изменений.

## Implementation

Изменить только `app/sections/CaseLab3Hero.tsx` и `app/sections/CaseLab3Speakers.tsx`. Вынесение данных в общий модуль не требуется: для этой точечной замены достаточно синхронно обновить шесть текстовых значений.

## Verification

Проверить совпадение новых формулировок в обоих компонентах, отсутствие старых тем, затем запустить релевантные тесты, TypeScript, lint и `git diff --check`.
