# План: персональная одноразовая ссылка Case Lab III

## Цель

Добавить приватную ссылку на один билет Case Lab III по цене 5 000 ₸ без изменения публичной цены 7 980 ₸. Использовать существующий TipTop Pay, фискализацию, выдачу билета и QR.

## Шаги

1. Расширить типы и серверную валидацию заказа приватным токеном; хэшировать токен на сервере и не передавать его в SQL в открытом виде.
2. Добавить SQL-миграцию с приватными предложениями, атомарными RPC для availability/создания заказа/выпуска предложения и триггерами, которые освобождают claim после failed/expired и помечают предложение redeemed после paid.
3. Добавить приватный динамический маршрут с `noindex` и передать токен в существующий `CaseLab3CheckoutProvider`; публичный маршрут оставить без изменений.
4. Добавить безопасную одноразовую CLI-команду генерации live-ссылки без хранения сырого токена в репозитории.
5. Дополнить контрактные/исходниковые тесты, прогнать полный набор тестов, TypeScript и production build.

## Границы

- Не менять `.env`, цены в публичной конфигурации, возвраты и существующий check-in.
- Не добавлять админ-панель и промокоды.
- До отдельной команды пользователя не делать commit/push/deploy.
